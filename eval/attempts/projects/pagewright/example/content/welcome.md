## What this is

A small example site. Each `.md` file in `content/` becomes a page, and the
front page lists them all.

- headings, paragraphs and lists
- **bold**, *italics*, `code` and [links](/welcome/)
- fenced code blocks

> Build it with `python3 -m pagewright example/site.json`.

```
content/welcome.md  ->  public/welcome/index.html
```

# Security

This plugin is jevmem's side pane for Claude Code. It reads three local files the jevmem command writes under the project's `.jevmem/` folder and runs that command on your machine; it sends nothing anywhere and reads no key. One document covers it with jevmem: [SECURITY.md](https://github.com/Avinash-jetwani/jevmem/blob/main/SECURITY.md) in the repository says what the pane reads and runs, what jevmem sends where, what it stores and what it scrubs.

To report a vulnerability, use GitHub's [private vulnerability reporting](https://github.com/Avinash-jetwani/jevmem/security/advisories/new). Please do not open a public issue for a security problem. More: [Reporting a vulnerability](https://github.com/Avinash-jetwani/jevmem/blob/main/SECURITY.md#reporting-a-vulnerability).
